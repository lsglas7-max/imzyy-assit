IMZYY XL LAUNCHER v6.0.0 — GITHUB ACTIONS SETUP

IMPORTANT: The contents of this ZIP must be placed at the ROOT of your GitHub
repository. Do not upload the outer folder as a nested directory.

The correct repository layout must look like this:

  .github/
    workflows/
      android-debug.yml
  android/
  scripts/
  README.md
  THIRD_PARTY_NOTICES.md

The workflow is not listed in the Actions tab until GitHub sees the YAML file
at exactly: .github/workflows/android-debug.yml
and that file has been committed to the repository's DEFAULT BRANCH.

Recommended method:
1. Open the target GitHub repository.
2. Extract this ZIP on your device/computer.
3. Upload the CONTENTS inside the extracted folder to the repository root.
   Include the hidden .github folder. Do not upload only README or android/.
4. Commit the files to the default branch (usually main).
5. Open Actions and refresh. Select:
   "Build IMZYY XL with embedded Amethyst Engine"
6. Tap "Run workflow" and choose the default branch.

If .github is hidden by your file manager, enable "Show hidden files" before
uploading. If GitHub's mobile upload page does not let you upload the .github
folder, use GitHub Desktop, git, or create the workflow file directly in the
GitHub website using Add file > Create new file and enter this exact path:
.github/workflows/android-debug.yml

The workflow builds one ARM64 APK and uploads it as:
imzyy-xl-amethyst-engine-arm64-debug

This ZIP is source code, not a prebuilt APK. The build downloads Amethyst and
the official JRE bootstrap asset during Actions.
